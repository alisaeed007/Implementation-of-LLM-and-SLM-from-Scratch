# Implementation-of-LLM-and-SLM-from-Scratch
Implementation of LLM and SLM from Scratch
Implementation of LLM and SLM from Scratch

This project contains a Jupyter Notebook that implements Large Language Models (LLM) and Small Language Models (SLM) from scratch using PyTorch.

It covers:
- Text preprocessing and tokenization
- Word embeddings
- Self-attention mechanism
- Transformer-based model (decoder style)
- Training loop
- Text generation

The goal of this project is to understand how modern language models (like GPT) work internally without using high-level libraries.

How to run:
1. Install dependencies: pip install torch numpy
2. Open Jupyter Notebook
3. Run implementation-of-llm-from-scratch.ipynb
